# GLOSSARY

| Term | Meaning here |
|---|---|
| Artifact | a private web page hosted by Claude; here a Dashboard type artifact |
| As-of date | the day a number was true; every money number has one |
| Asset (store) | an uploaded file the page reads; here one JSON per dataset |
| Backup kit | the zip with every dataset, documents, schema, restore steps and a hash manifest |
| Calc | a pure function of datasets and other calcs that returns rows or a Needs message |
| Card (page) | one block on a page with one key number or chart, chips and an About this fold |
| Check (C1 to C29) | a correlation test between two numbers that must agree |
| Chip | a short status word on a card: Needs, Planned, Limit reached, Stale |
| Combined loan to value | (first lien plus other liens) divided by home value |
| Coverage | how much of the picture the data fills; three rings: Picture, Scores, Explained |
| Dataset | one JSON file of flat rows; one topic |
| Dataset document | the store record for a dataset: title, description, source, updated |
| DTI (debt to income) | monthly debt payments divided by monthly gross income; headline leaves rent out unless there is no mortgage |
| Drift | reported balance minus expected balance for an account; unexplained spending when positive on a card |
| Essentials | bills and debt payments you cannot skip |
| Fold (About this) | a closed section of a card holding source, how worked out and explanations |
| HSA | health savings account (US) |
| Harness | the browser-free test engine that loads data and runs calcs like the runtime does |
| Invariant | a rule that must hold on every data shape, checked by page/invariants.js |
| Liability | a debt row: card, loan, mortgage, tax or medical balance |
| Loan to value (LTV) | first lien divided by home value |
| Needs | the plain text shown instead of a number when an input is missing; becomes a task |
| Overlay | the private per-user db document that holds task actions until Claude folds them in |
| Plan year | the calendar year the contribution limits and chosen percent apply to |
| Planned | a feature designed but not built; shown with a Planned chip |
| Profile question | "Do you have X?" for one category; answer yes, no or unknown |
| Quest | a group of tasks that unlocks one thing; no points |
| Registry (placeholders) | the single list of planned and needed items shown as "Planned and needed" |
| Runtime | the host that loads datasets and runs the page and its calcs |
| Runway | months of essentials the cash covers |
| Smart order | payoff ranking: past due, late, then highest effective rate, then smaller balance |
| Starter row | one row with every value null that lets an empty dataset load |
| Tile | a small number box inside a card that links to its larger chart or table |
| Tile link rule | every tile jumps to the larger chart or table showing the same number unless none exists |
| Trail | the payoff progress line per debt |
